**NexusFlow ERP** is a production-grade, multi-tenant enterprise workflow and task automation engine. Built with a clean, minimalist architecture, it provides secure tenant isolation, role-based user directory management, real-time Kanban pipeline tracking, and immutable audit logging for enterprise-grade compliance.

🔗 **[Explore Live Production Portal](https://vaibhavsingh8395.github.io/nexusflow-workflow-engine/)**

---

## 🌟 Key Features

* **Multi-Tenant Architecture:** Secure company workspace isolation with independent state partitioning and custom tenant switching.
* **Team & User Directory:** Company administrators can manage personnel assignments, invite new colleagues, and assign departmental roles (*Business Analyst*, *Systems Engineer*, *Database Administrator*).
* **Operational Kanban Pipeline:** Real-time task synchronization across departmental clusters with instant priority filtering, status transitions (*Backlog*, *In Progress*, *In Review*, *Completed*), and live KPI metrics.
* **Enterprise Audit Logs:** Immutable event tracking recording every tenant registration, user session login, invitation, and task modification for SOC2 and ISO-27001 readiness.
* **Modern Minimalist UI:** Designed using Host Grotesk and Instrument Sans typography, soft surface cards, fine borders, and an open light-surface aesthetic.

## 🛠️ Technology Stack

* **State Persistence:** Normalized relational schema backed by browser Session/Local Storage.
